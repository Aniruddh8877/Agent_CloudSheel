# Welcome to Aniruddh Web Agent
*Last modified: 2026-10-17 22:10:00*

Welcome to your Python-powered autonomous agent!

### What this agent can do:
1. **Live Web Search**: Search DuckDuckGo without requiring any API keys.
2. **Page Content Extraction**: Extract clean readable text from articles and technical blogs.
3. **Workspace Notes**: Read, create, update, search, and delete Markdown notes right from chat or through the Notes drawer.
4. **Python Math & Sandbox**: Compute compound interest, evaluate formulas, execute string manipulation, or process data structures.
5. **Real-time Clock & Timezone**: Check today's date, deadlines, and live time.

Try asking:
